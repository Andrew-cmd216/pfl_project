# Speech Analyzer

Сервис на FastAPI принимает один WAV-файл и возвращает длительность, среднеквадратичную амплитуду и статистику пауз в JSON.

## Установка и запуск

Нужны Python 3.12 или новее и [uv](https://docs.astral.sh/uv/). Из корня проекта выполните:

```sh
uv sync --locked --no-editable
uv run --no-sync uvicorn speech_analyzer.main:app --host 127.0.0.1 --port 8000
```

На системах с Make можно использовать `make install` и `make run`. Версии зависимостей зафиксированы в `uv.lock`. Переменные окружения и секреты для запуска не требуются.

## Пример запроса

Откройте Swagger UI по адресу `http://127.0.0.1:8000/docs` и загрузите WAV в `POST /analyze` через поле `file`, либо выполните:

```sh
curl -F "file=@sample.wav" http://127.0.0.1:8000/analyze
```

В Windows PowerShell при необходимости используйте `curl.exe`. Для секунды тишины ответ выглядит так:

```json
{"duration_seconds":1.0,"rms":0.0,"pause_count":1,"pause_seconds":1.0}
```

`GET /health` возвращает `{"status":"ok"}`. Некорректный WAV возвращает HTTP 422, файл больше 25 МиБ — HTTP 413.

## Поддерживаемые записи и расчёты

- WAV с PCM 16, 24 или 32 бита, один или два канала, 16–48 кГц, от 0,5 до 120 секунд.
- Для стерео каналы усредняются. RMS измеряется по амплитуде цифрового сигнала от 0 до 1.
- Пауза — последовательность тихих окон примерно по 20 мс с RMS ниже 0,01 и суммарной длительностью от 200 мс. Учитывается тишина на краях записи. Результат чувствителен к уровню записи и шуму.
- Лимит файла проверяется после разбора multipart-запроса. При публичном развёртывании размер всего запроса следует ограничить на уровне прокси.
- Первый прототип обрабатывает одну запись за запрос. CSV, графики, сравнение записей и определение речевой активности остаются за рамками этой версии.
